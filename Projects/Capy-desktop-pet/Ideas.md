# Main idea
I want to have background less app which display as capybara moving randomly in a given window frame (could be a fixed size or dynamically expanding the environment).

## Initial concept
![[Projects/Capy-desktop-pet/Initial idea concept.excalidraw.md#^frame=R3QgQPTw|App Idea]]
## Stack
For the window front-end part of this project, I'll explore [Avalonia UI](https://avaloniaui.net/) (uses C#). 
And C# in general to control its behavior. Don't think this could require other tools for now.

# MVP (30-days)
Being able to explore Avalonia UI to show a capybara without a background just rendering the grass.
Capy should be able to walk randomly around the area (fixed).
There should be a rendered sun.

## Bonus
Should include a puddle for Capy with an animation for entering-swimming-getting out.
