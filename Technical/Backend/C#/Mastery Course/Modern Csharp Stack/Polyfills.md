Refers to the practice of using newer features of a language from older releases of a framework.

>[!EXAMPLE]
>.NET Framework 4.8 would be fixed to use C# version 7.3 (Done by the [[TFM]]). 
>By using [PolySharp](https://github.com/Sergio0694/PolySharp) we can access features that were introduced in newer versions of the language!
