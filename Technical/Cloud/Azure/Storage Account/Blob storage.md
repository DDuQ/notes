# Definition

Azure Blob Storage ==stores **text** and **binary data** as objects in the cloud==. 

It can store text and binary data in one of the following types of blobs:
## **Block blobs**
Optimized for streaming (Used for images, PDFs, ZIPs, videos, backups).
## **Append blobs**
Optimized for append operations (such as logging operations).
## **Page blobs**
Optimized for random read/write operations, and which provide the ability to write to a range of bytes in a blob.
