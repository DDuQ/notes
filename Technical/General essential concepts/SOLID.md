
# Definition

Those are a set of principles that allows developers to create software designs that are easier to understand, maintain and extend leading to high quality software that is robust and adaptable.
# Single Responsibility

A class should only have one reason to change; should have only one responsibility or purpose.
# Open / Closed

Software entities (classes, functions, modules, etc.) should be open for extension but closed for modification.
# Liskov Substitution

Objects of a base class should be replaceable with object of its derived class without breaking the program.
